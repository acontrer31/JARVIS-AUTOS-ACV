# JARVIS AUTOS ACV

Panel de control JARVIS para Agencia Alcover Automotores — réplica visual estática del dashboard, construida en HTML, CSS y JavaScript puro (sin frameworks ni dependencias externas).

## Uso

Abrí `index.html` en el navegador, o serví la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

## Contenido

- `index.html` — estructura del dashboard (sidebar, topbar, tarjetas, gráficos, panel de análisis).
- `style.css` — tema oscuro estilo sci-fi (paleta cian/negro, efectos de glow).
- `script.js` — reloj en vivo, navegación activa e interacciones mock (sin backend ni datos reales).

Los datos mostrados (ventas, leads, inventario, etc.) son de ejemplo.
